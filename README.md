# 月球早期地质研究：AI 协作规范

## 1. 项目背景

这是一个长期月球科学研究与学习项目，主要使用 Python，已有 `src/` 可复用库及 `experiments/lunar/` 实验体系。

## 2. 核心约束

- 保留现有项目结构和功能，不擅自进行大规模重构。
- 通用能力放在 `src/`，科学实验放在 `experiments/lunar/`。
- 原始大型数据存储在外部自己路径，不复制进 Git 仓库。
- 新建实验目录时，说明目录结构、输入、输出及验收条件。
- 不得以未经验证的机器学习结果代替地质学判断。
- 不得编造数据来源、波长、仪器精度、矿物组成或科学结论。
- 科学解释必须区分观测事实、模型假设和推测。

## 3. AI 的职责

负责数据检索、格式解析、预处理、工程实现、批量计算、单元测试、文献整理及实验记录。

实现过程中必须明确数据单位、坐标系统、缺测值、处理参数和适用范围。

## 4. 研究者保留的职责

研究者需要亲自学习和验证关键科学方法，包括光谱吸收特征、地质年代解释、岩石矿物学、重力异常及候选区域证据评估。

对于涉及新数学模型、新物理假设或新地质学概念的任务，先说明原理和验证方案，不要直接用大型黑箱流程替代学习。

## 5. 每次任务必须交付

1. 本次实际新增或修改的文件清单及目录 tree。
2. 每个重要模块的用途、输入、输出与单位。
3. 数据来源与相关文献。
4. 执行的测试及结果，未执行的测试明确说明。
5. 计算结果、适用条件及尚未解决的问题。
6. 研究者需要理解的核心知识和可自行完成的小实验。

## 6. 完成标准

代码运行成功不等于科学结论成立。

只有在数据可追溯、处理方法明确、数值结果可复现、关键假设经过审查时，才能将任务标记为完成。

涉及月球早期地质保存情况时，必须明确说明现有证据是否足以支持候选区域判断，不能把模型输出直接表述为已经确认的地质事实。
